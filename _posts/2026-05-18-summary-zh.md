## [使用 Git 的 --author 标志对抗 GitHub 上的 AI 机器人垃圾信息](https://archestra.ai/blog/only-responsible-ai) ⭐️ 7.0/10

一篇博客文章描述了一种技术，通过使用 Git 的 --author 标志检查提交作者信息，来过滤 GitHub 仓库中的 AI 生成垃圾拉取请求。该方法帮助维护者根据电子邮件和姓名不匹配自动拒绝可疑贡献。 随着 AI 生成的垃圾信息在开源社区中日益普遍，这种轻量级方法提供了一种减少维护者工作负担并保护仓库完整性的实用途径。该技术凸显了区分合法贡献者与自动化机器人的持续挑战。 该技术依赖于这样一个事实：当提交者电子邮件与 GitHub 账户电子邮件匹配时，GitHub 会将提交链接到用户配置文件并授予贡献者身份。一个安全隐患是，恶意行为者可能在有一个小提交被接受后获得更高的权限，正如 GitHub 文档所指出的。

hackernews · ildari · May 18, 15:24 · [社区讨论](https://news.ycombinator.com/item?id=48181125)

**背景**: Git 的 --author 标志按作者姓名或电子邮件过滤提交，常用于仓库历史分析。在 GitHub 中，任何提交被合并到仓库的用户被视为贡献者，并可能绕过某些操作（例如运行来自 fork 的拉取请求）的审批要求。如果垃圾机器人设法让琐碎的更改被接受，这种基于状态的权限模型就可能被利用。

**社区讨论**: 评论者提出了关于贡献者权限升级的安全担忧，并批评 GitHub 缺乏基本的垃圾信息防御功能。一些人建议使用基于 ELO 的声誉系统，或禁止高拒绝率账户创建拉取请求，以缓解该问题。

## [欧盟数字市场法案使火狐在欧新增 600 万用户](http://news.zol.com.cn/1182/11821187.html) ⭐️ 7.0/10

欧盟《数字市场法案》（DMA）强制要求在移动设备上显示默认浏览器选择屏幕，导致火狐在欧新增逾 600 万用户。第三方分析显示，选择屏幕上线后，火狐在欧盟的 iOS 日活用户比政策前预测高出 113%，Android 高出 12%。 这表明 DMA 在促进浏览器竞争、减少预装浏览器主导地位方面产生了切实影响。它也证明了监管干预能有效改变数字市场中的用户选择行为，可能影响全球类似政策。 该数据涵盖 iOS 选择屏幕上线后 15 个月，以及 Android 上未明确的时间段。Mozilla 已呼吁监管机构将相同规则扩展至个人电脑。

telegram · zaihuapd · May 18, 02:32

**背景**: 欧盟《数字市场法案》（DMA）是一项于 2022 年 11 月生效、2023 年 5 月适用的法规。它将大型在线平台指定为‘守门人’，并施加义务以确保公平竞争和可竞争性。其中一项要求是守门人必须允许用户轻松更改默认设置，包括选择默认浏览器。这导致欧盟移动设备上出现了选择屏幕。
