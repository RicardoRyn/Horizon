## [FFmpeg 9.1 推出改进的 AAC 编码器](https://hydrogenaudio.org/index.php/topic,129691.0.html) ⭐️ 8.0/10

FFmpeg 9.1 包含一个新的原生 AAC 编码器，相比之前的编码器显著提升了音频质量，解决了长期存在的如啁啾伪影等问题。 这一升级减少了对 Apple Core Audio 等外部编码器的依赖，增强了 FFmpeg 的独立音频编码能力。同时也重新引发了关于 AAC 与 Opus 编码效率的讨论。 该编码器主要针对 48 kHz 音频进行优化，也支持 44.1 kHz 和 96 kHz，但建议使用 48 kHz 以获得最佳质量。它包含一个针对立体声感知噪声替换（PNS）解码器 bug 的变通方案。

## [Cloudflare 推出通过 HTTP 402 收费的变现网关](https://blog.cloudflare.com/monetization-gateway/) ⭐️ 8.0/10

Cloudflare 宣布推出 Monetization Gateway，允许客户使用 HTTP 402 状态码和 x402 协议对其背后的任何资源（网页、数据集、API、MCP 工具）进行收费，初始结算使用稳定币。 这简化了互联网上的小额支付，特别是为 AI 代理和自动化系统提供了标准化的支付层，影响了内容创作者、API 提供商和网络基础设施，无需传统支付堆栈。 Monetization Gateway 使用开放的 x402 协议，该协议重新利用了 HTTP 402 状态码，初始通过 Coinbase 以稳定币结算。Cloudflare 处理支付堆栈，该服务目前处于等待列表阶段。

**背景**: HTTP 402（需要付款）是 HTTP 标准中定义的状态码，但实际很少使用。x402 协议是一个开放标准，利用 HTTP 402 实现机器原生支付，常与加密货币结合使用。Cloudflare 是一家主要的 CDN 和网络基础设施提供商，这一集成对广泛采用具有重要意义。
