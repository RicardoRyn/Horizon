## [WATaBoy：将 Game Boy 指令 JIT 编译为 WASM，性能超越原生解释器](https://humphri.es/blog/WATaBoy/) ⭐️ 8.0/10

WATaBoy 项目证明，将 Game Boy CPU 指令即时编译到 WebAssembly（WASM）的性能优于用 C 或 Rust 编写的原生解释器。 该方法利用浏览器对 JavaScript 和 WASM 的高度优化的 JIT 编译器，即使在 iOS 等限制传统 JIT 但允许浏览器 JIT 的平台上也能实现高性能模拟。 该项目针对 Game Boy 模拟，比较了原生解释器与 WASM JIT 后端；发现 Firefox 比 Chrome 或 Safari 慢 25%，可能是由于 WASM 运行时优化的差异。

**背景**: 即时编译（JIT）在运行时将代码翻译为本地机器码，对频繁执行的路径提供比纯粹解释更好的性能。WebAssembly（WASM）是一种为在浏览器中高效执行而设计的二进制指令格式，同样受益于浏览器内置的 JIT 引擎。通过生成 WASM 而非本地代码，该项目绕过了某些平台的 JIT 限制，同时仍获得了 JIT 加速。
